# 🫁 Lung Cancer Prediction Using Machine Learning

## 📌 Project Overview

This project uses Machine Learning to predict lung cancer based on health and lifestyle-related features.

The project includes data preprocessing, Exploratory Data Analysis (EDA), model training, evaluation, and a Streamlit web application.

> ⚠️ **Disclaimer:** This project is for educational purposes only and is not intended for medical diagnosis.

---

## 🎯 Objective

- Clean and preprocess the dataset
- Perform Exploratory Data Analysis
- Train Machine Learning models
- Evaluate model performance
- Build a lung cancer prediction application

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Jupyter Notebook
